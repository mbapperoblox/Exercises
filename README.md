# OOP Exercises

Solutions for the Python Object-Oriented Programming short exercise.

## Files
- `operator_overloading.py`: Special methods (`__add__`, `__sub__`, `__mul__`, comparisons) with built-in tests.
- `inheritance.py`: Class inheritance, method overriding, and `super().__init__()` examples with built-in tests.

## How to run
Run `python operator_overloading.py` or `python inheritance.py` in your terminal.
